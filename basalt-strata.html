一张 16G 显存的游戏卡，怎么跑得动一个 82G 的千问？这是前段时间火起来的推理引擎 Strata 带来的事——它让不少人在自己的电脑上第一次跑起了这种体量的模型。现在，从 Strata 改良而来的 Basalt，又把速度往前推了一步。这篇讲清楚三件事：Strata 的内存分层是怎么把 82G 装进 16G 显存的，Basalt 到底改了什么，以及社区实测的提速数字为什么对不上「2 倍」的宣传口径。

一张游戏卡，怎么跑得动这么大的模型

先看数字：Qwen3.8-Flash-Next 是一个 MoE 模型，BF16 全量权重在 80 多个 GB，而一张 RTX 5070 Ti / 5080 只有 16G 显存。显存装不下，常规推理框架（llama.cpp、vLLM 的纯显存路径）直接没地方放。

Strata 的答案是分层：把 MoE 模型里占大头的路由专家（routed experts）权重放在系统内存（RAM）里，显存只保留 KV cache 和激活缓存。推理时显存命中的算显存，没命中的专家从内存流式读进显存再算。于是 82G 的模型只需要显存装得下 KV 和激活，专家权重全部落在内存上——16G 显存 + 64G 内存就能跑，专家甚至不用全放下，剩下的还能落到 SSD。

这套方案有两个硬约束，别忽略：

  • 只支持 RTX 50 系（Blackwell，sm_120）：40 系、30 系的卡不在支持范围。
  • 模型限 Qwen3.8-Flash-Next 和 DeepSeek-V4.1-Flash：引擎是为这两个 MoE 模型专门写的，不是通用框架。

Strata 是什么

Strata 是 MIT 协议的 MoE 本地推理引擎。它的核心设计就一条：显存只放缓存，专家权重常驻内存。社区实测里它在 5070 Ti 16G 上能开 20 万上下文（IQ3_XXS 量化），5080 16G 上能开 192K，内存里常驻几十个 GiB 的专家，不占 SSD。

但 Strata 有个被反复吐槽的点：decode 慢。原因不在显卡，在 CPU 侧——每个 decode 窗口都有一大段串行开销，花在 CPU 做专家点积调度、以及主机和 GPU 之间的握手传输上。这正是 Basalt 要动的地方。

Basalt 改了什么

Basalt 是 Strata 的 fork，作者 jesdga。它没有重写 CUDA kernel——GPU 侧的算力部分原样保留。改动集中在CPU 调度层，这是理解「它为什么快」和「它为什么不是 2 倍」的关键。

三个改动点

社区实测文章里点名的改动有三处：

  • 更细的 row-range 任务切分：把 CPU 侧专家的串行点积按更细的 row 区间切开，让多核能更均匀地并行，而不是长尾串行。
  • i-quant 走 AVX-VNNI：量化专家的整数内核改用 AVX-VNNI 指令，在支持的 CPU 上单条指令吞吐更高。
  • 单文件 .basalt 格式：模型打包成一个 .basalt 文件，加载和寻址路径简化。

注意这三条全在 CPU 侧。所以 Basalt 的提速幅度，取决于你的 CPU 能不能吃下这些优化——这一点直接决定了实测数字的差异，下一节展开。

快多少，为什么不是 2 倍

视频标题口径是「快 50%」，社区里流传最广的说法是「快 2 倍」。两个数字都对，也都对不上，原因是机器不同。

实测数字

同一台机器、同一个模型（Qwen3.8-Flash-Next，IQ3_XXS 量化，250W 锁功耗），社区实测 prefill / decode 的倍率：

场景Strata 0.2.9Basalt 0.3.0倍率
prefill 64K1960 tok/s2725 tok/s1.39×
decode（MTP 接受率 65–70%）58 tok/s73 tok/s1.26×
decode（MTP 接受率 97–98%）104 tok/s148 tok/s1.42×

decode 的差异主要来自 MTP 接受率：接受率高时一个推测窗口里挤进更多 token，那段固定开销被摊薄。两个引擎都是这个规律。

另一台机器上（RTX 5080 16G + 96G 内存，NVFP4 量化），prefill 跑到 5400–6000 tok/s，比 Strata UD-Q4_K_XL 快约 35–41%，生成快约 25–60%。这些数字落在视频「快 50%」的取整口径附近。

瓶颈在 CPU 和 PCIe

那「2 倍」从哪来？基本出自带 AVX-VNNI 的桌面 CPU（9950X、285K 这类），AVX-VNNI 把量化专家内核的单条吞吐拉满。但换成没有 AVX-VNNI 的 CPU，提速就缩回 1.26–1.42 倍。证据有三处：

  • 引擎启动日志自己写：这台机器 this CPU has no AVX-512: the expert kernels run on AVX-2——专家内核退回 AVX2，AVX-VNNI 那条路根本没走。
  • 把显存里的专家数从 6.7 GiB 提到 13.3 GiB（翻倍），速度只涨 1.2–1.4 倍——瓶颈不在显存。
  • decode 每个窗口约 19ms 固定开销 + 4.1ms/token，48 层摊下来每层约 0.4ms，全花在 CPU 侧串行专家点积和主机-GPU 握手上，不在显卡算力。PCIe 3.0 平台的 H2D 带宽只有 13.8 GB/s，又是一堵墙。

结论：Strata 慢是因为这堵 CPU/PCIe 的墙，Basalt 也只快在墙内能优化的那部分。带 AVX-VNNI 的 CPU 能把墙推得更高，所以测出 2 倍；普通 CPU 推不动，只有 1.3 倍上下。
